# Unused / standalone scripts

Scripts in this directory are not part of the web stack (`api/` + `frontend/`). They are kept here for manual use and later review.

Run from the repo root:

```bash
python unused/run_backtest.py
python unused/IBConnect.py
python unused/benchmark_backtest.py --help
python unused/regression_checks.py
python unused/test_data.py
python unused/test_indicator.py
```
